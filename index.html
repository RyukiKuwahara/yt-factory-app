yt-factory

yt-factory は、運営者が自分の YouTube チャンネルを運営するための個人用のツールです。一般の利用者向けのサービスではありません。

YouTube API Services を使い、運営者自身のチャンネルへの動画のアップロードと、そのチャンネルの分析データの閲覧を行います。

  • プライバシー ポリシー（Privacy Policy）

English

yt-factory is a personal tool used only by its operator to manage the operator's own YouTube channels. It is not a service offered to the general public.

It uses YouTube API Services to upload videos to the operator's own channels and to read analytics data for those channels.
