yt-factory プライバシー ポリシー

最終更新日: 2026年10月25日

1. このアプリについて

yt-factory（以下「本アプリ」）は、運営者が自分の YouTube チャンネルを運営するための個人用のツールです。本アプリは YouTube API Services を使用しています。本アプリを使うことで、YouTube 利用規約に同意したものとみなされます。Google によるデータの扱いは Google プライバシー ポリシーをご覧ください。

2. 取得する情報

本アプリは、運営者が Google アカウントで許可した範囲で、次の情報にアクセスします。

  • 運営者のチャンネルと動画の情報（チャンネル名、動画の題名・公開状態など）
  • 運営者のチャンネルの分析データ（再生回数、視聴維持率など）
  • 動画のアップロードと、題名・説明・サムネイルなどの設定
  • API キーで取得する公開データ（公開されている動画の検索結果など）

本アプリは、運営者以外の利用者の個人情報を収集しません。利用者の端末に Cookie などを保存することもありません。

3. 使い方

取得した情報は、運営者自身のチャンネルへの動画の投稿と、そのチャンネルの改善のための分析にだけ使います。広告やほかの目的には使いません。

4. 保存と共有

  • 情報は運営者が管理する環境（運営者のコンピューターと、運営者のバックアップ）にだけ保存します。第三者に提供・販売・共有しません。
  • API キーで取得した公開データは、30日以内に削除します。
  • 認可のトークンは運営者の手元に保存し、外部に送りません。

5. 許可の取り消しとデータの削除

本アプリへのアクセスの許可は、Google アカウントのセキュリティ設定（サードパーティのアクセス）からいつでも取り消せます。許可が取り消されたときは、本アプリが保存していた、その許可で取得したデータを7日以内に削除します。

yt-factory Privacy Policy

Last updated: October 25, 2026

1. About this app

yt-factory ("the App") is a personal tool used by its operator to manage the operator's own YouTube channels. The App uses YouTube API Services. By using the App, you agree to be bound by the YouTube Terms of Service. See the Google Privacy Policy for how Google handles data.

2. Information accessed

Within the scope authorized by the operator's Google account, the App accesses:

  • Information about the operator's channels and videos (channel name, video titles, privacy status, etc.)
  • Analytics data for the operator's channels (views, audience retention, etc.)
  • Video uploads and settings such as titles, descriptions and thumbnails
  • Public data obtained with an API key (e.g. search results for public videos)

The App does not collect personal information about anyone other than the operator, and does not store cookies or similar data on users' devices.

3. How information is used

Information is used only to publish videos to the operator's own channels and to analyze those channels to improve them. It is not used for advertising or any other purpose.

4. Storage and sharing

  • Information is stored only in environments controlled by the operator (the operator's computer and the operator's backups). It is not provided, sold or shared with any third party.
  • Public data obtained with an API key is deleted within 30 days.
  • Authorization tokens are kept on the operator's computer and are not sent anywhere else.

5. Revoking access and deleting data

Access granted to the App can be revoked at any time from the Google account security settings page. When access is revoked, the App deletes the data it stored under that authorization within 7 days.
